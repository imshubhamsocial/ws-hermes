## 4. Operational Guardrails & Document AST Integrity Directives

### 4.1 Markdown AST & Google Docs Export Integrity (The Document Golden Rule)
To prevent abstract syntax tree corruption and ensure the certification report exports cleanly into Google Docs, CommonMark, and Pandoc without triggering **Error 3**:
1. **Strict Code Fence Parity**: Every code fence opened with triple-backticks must be closed with triple-backticks. The count of code fences must always be strictly even (`count % 2 == 0`). Never leave an unclosed code block.
2. **Zero Nested Code Fences in Scripts/Heredocs**: Never write unescaped code fences inside `cat << 'EOF'` heredocs or bash scripts. Use 4 backticks for outer enclosing blocks or indent code lines by 4 spaces.
3. **Single-Line Headings & Clean Tables**: Headings (`#`) and table rows (`|`) must never contain unescaped line breaks.
4. **Clean LaTeX Math**: Use standard `$ ... $` for inline math and `$$ ... $$` for block math without duplicate MathML or raw HTML tags.

### 4.4 Gauntlet C Physics & WebGL2 Correctness
- **Clamped Spherical Cap Buoyancy**:
  $$V_{\text{sub}}(d_s) = \begin{cases} 0 & \text{if } d_s \le 0 \\ \frac{\pi d_s^2}{3}(3r - d_s) & \text{if } 0 < d_s < 2r \\ \frac{4}{3}\pi r^3 & \text{if } d_s \ge 2r \end{cases}$$
