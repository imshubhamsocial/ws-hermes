## Non-Negotiable Google Docs & Gemini Web Safety Rules

To prevent formatting crashes and export errors, you must strictly comply with these six formatting invariants:

1. **Even Code Fence Parity**: Total count of triple backtick fences must be an **even integer** (code fence count % 2 == 0). Never wrap the markdown document in an outer code fence.
2. **Even Math Dollar Parity**: Total count of dollar signs must be an **even integer** (dollar count % 2 == 0). Every `$formula$` and `$$formula$$` must be strictly closed. Never use raw dollar symbols in prose or shell variables outside code blocks.
3. **Single-Line Table Rows**: Every table row must be on a **single physical line** (`| cell1 | cell2 |`). Never allow word-wrapping across table cells.
4. **Zero Unbackticked Angle Brackets**: Never write raw `<path>`, `<cmd>`, or `<name>` in prose. Always wrap placeholders in inline backticks (`<path>`) or write in Simplified Technical English ("strictly under 60 lines").
5. **Clean Code Blocks**: Never embed markdown links `[url](url)` inside code blocks. All URLs in code must be plain text strings.
6. **ASD-STE100 Compliance**: Use short, clear, active sentences under 25 words. Maintain clean glass-box precision.
