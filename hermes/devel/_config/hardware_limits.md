# Layer 3: Hardware Limits and Operating Rules

## Discrete GPU Envelope
- Device: NVIDIA GeForce RTX 3050 Laptop GPU (6,144 MiB physical GDDR6).
- Maximum Active VRAM: 5,800.0 MiB under 128K context.
- Maximum Quiescent VRAM: 100.0 MiB when daemon is stopped.
- Display Compositor: Wayland runs on Intel integrated GPU (`Disp.A: Off`).
